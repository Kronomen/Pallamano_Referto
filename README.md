# Referto Pallamano

Applicazione Blazor WebAssembly per la gestione del referto di una gara di pallamano.

## GitHub Pages
Il progetto è predisposto per la pubblicazione automatica tramite GitHub Actions. Il repository previsto è `Pallamano_Referto`.

Dopo il commit sulla branch `main`, il workflow `.github/workflows/deploy.yml` compila il progetto e pubblica `wwwroot` su GitHub Pages.
